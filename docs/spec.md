## 0. Сквозные требования

### 0.1 Хранение
- ✅ Мастерборд работает только после входа по почте (Cloudflare Access, решение F1). Кампании хранятся на сервере (Worker + D1), по документу на кампанию: `localCampaigns/{id}`; кампании, оставшиеся в IndexedDB браузера с прежних версий, переносятся на сервер кнопкой «Перенести все». Старые данные из `localStorage` сначала переносятся в IndexedDB, исходная строка остаётся в `masterboard.local-campaigns.v1.backup`.
- ✅ Повреждённые данные **не удаляются**: исходная строка сохраняется в резервный ключ, пользователь видит баннер с кнопкой «Скачать резервную копию».
- ✅ Экспорт/импорт кампании одним JSON-файлом (ручной бэкап до появления интеграций).
- ✅ Резервная копия (М5): каждую ночь мост кладёт все общие кампании в приватный репозиторий бэкапа (`мастерборд/`, файлами «Экспорта»); страница «Резервные копии» рядом со списком кампаний — итог последней копии, папка в GitHub, «Сделать сейчас» (`docs/contracts/lorebridge-masterboard.md`).
- ✅ Идентификаторы создаются через общий генератор (`src/model/ids.ts`), без коллизий при создании двух объектов в одну миллисекунду.
- ✅ Изменение сохраняется в фоне; при ошибке оно остаётся на экране, появляется сообщение и кнопка «Повторить». Неотправленная правка общей кампании хранится в браузере как черновик: переживает обрыв связи и перезагрузку, уходит при восстановлении связи или по «Синхронизировать».

### 0.2 Единая модель сессии
- ✅ Устаревшие поля `firstSession*` мигрируются в `sessionRecords` и удаляются из записи кампании; после миграции единственный источник — `sessionRecords`.
- ✅ Признак «кампания готова» не зависит от количества заметок: удаление последней заметки не возвращает пользователя в онбординг.

### 0.3 Навигация
- ✅ Навигация кампании (общая для дашборда и сессий) содержит все разделы: Обзор, Сессии, Сюжет, Пульт, Библиотека, Связи, Заметки, Заготовки, Команда, Печать, Публикация.
- ✅ Неизвестный `section` ведёт на Обзор, а не на пустую страницу.
- ✅ Мёртвый код удалён: `LocalLiveSession.tsx`, недостижимые ветки `LocalSessionContext` / `LocalSessionReview` в `LocalNewCampaignPage.tsx`, витрины `/demo/*` с фикстурами (27.09.2026).

### 0.4 Качество
- ✅ Для каждой области есть unit-тесты логики (`src/local/*.test.ts`) и сценарии интерфейса (`src/pages/*.ui.test.tsx`).
- ✅ Testing Library + jsdom подключены; сценарии интерфейса — `src/pages/localCampaign.ui.test.tsx`.
