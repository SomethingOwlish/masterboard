## Роли внешних систем (R3)

| Роль | Системы | Сколько у кампании | Что там живёт |
|---|---|---|---|
| **Мир** | Лорбук | 0..1 | лор: локации, фракции, события, лор/статьи, слухи, карты |
| **Стол** | ЛавГеймс **или** КК9 | 0..1 | персонажи игроков, НПС, существа, предметы, раздатки, письма; статы |
| **Система** | SystemSetup | 0..1 | правила и схемы полей (только чтение) |

Правила отправки по умолчанию (меняются в «Интеграциях» и в карточке):
- лор (`location`, `faction`, `event`, `lore`, `rumor`, `map`) → мир;
- персонажи и вещи (`character`, `npc`, `creature`, `item`, `handout`, `letter`) → стол;
- `note`, `audience`, `home-rule` → только Мастерборд.

## 1. Основа при создании (R1) — этап 1

- В окне «Новая кампания» блок «Основа»: строки «Мир (Лорбук)», «Стол (ЛавГеймс / КК9)», «Система (SystemSetup)», у каждой переключатель и выбор записи. Можно включить любые.
- Если название пустое, оно подставляется из первой выбранной основы.
- Кампания создаётся со связями (`campaign.integrations`). Сразу после создания открывается кампания с окном «Что забрать из основы» (импорт по источникам).
- Без моста блок показывает «Интеграции не настроены на сервере» и не мешает создать кампанию с нуля.

**Приёмка:** создать кампанию с миром и столом → кампания связана с обоими → открыт выбор импорта из обоих источников.

## 2. Поля из основы (R2) — этап 3

- Базовые поля типа (`ENTITY_FIELDS`) остаются.
- Поля основы: для каждого типа — поля, которые отдаёт схема системы (мост, `GET /mb/schema`, если есть) и поля, встреченные у импортированных записей мира/стола этого типа.
- Редактор показывает базовые поля, затем «Из основы»; длинные поля — многострочные.

## 3. Где живёт сущность (R3, R10) — этап 1

- `campaign.publishRules`: тип → список ролей (`world`, `table`). По умолчанию — таблица выше.
- В редакторе сущности строка «Где хранить»: «Только здесь» + чипы подключённых мира и стола. По умолчанию — по правилу типа. Выбор хранится в `entity.destinations`.
- При сохранении сущность с назначениями ставится в очередь «Публикации» (создать или обновить); отправка — как раньше, через проверку.

## 4. Навигация и вёрстка (R4, R12) — этап 2

- Меню кампании из групп: **Подготовка** (Обзор, Сессии, Сюжет, Пульт) · **Мир** (Библиотека, Связи, Заметки, Заготовки) · **Команда** · **Обмен** (Импорт, Интеграции, Публикация, Печать). Группа открывает список разделов; активный раздел подсвечен.
- Шапки разделов компактные: заголовок и действия в одну строку, описание — короче.
- Исправить: моноширинный шрифт в обзоре, неверную подпись «сохранено в браузере / интеграции отключены» у общих кампаний, кнопки лесенкой в обзоре, огромную пустую карточку «Новая кампания».

## 5. Поиск (R5) — этап 2

- Библиотека: текст (включая описание), тип, теги, видимость, статус, источник (система), сортировка.
- Общий поиск Ctrl+K: сущности, секреты, часы, арки, сессии, пункты планов; Enter открывает.
- Сохранённые фильтры библиотеки у каждого мастера.

## 6. Импорт (R6) — этап 4

**Раздел «Импорт» в кампании:**
- Плитки источников: подключённые мир, стол, система (кнопка «Выбрать записи»), JSON сессий, JSON кампании (файл).
- История импортов: когда, откуда, сколько записей.
- Задачи после импорта (создаются автоматически, отмечаются): записи без тегов, записи без описания, записи типа «заметка», пришедшие из мира (проверить тип), конфликты полей при обновлении.

**Страница «Импорт» на главной:** импорт кампании из файла, создание кампании из основы (как в R1).

**Разбор входящих:** на главной кампании (Обзор) у каждой быстрой записи кнопки: в сущность (выбор типа), в задачу, в часы, в секрет, удалить.

## 7. Пачки (R7) — этап 3

- Библиотека: переключатель «Карточки / Таблица». Таблица: выделение строк, «выбрать все по фильтру», сортировка по колонкам.
- Действия над выделенным: теги (добавить/убрать), видимость, в архив / из архива, отправить в системы (в очередь), в план сессии, связать с сущностью, экспорт выбранного в JSON.

## 8. Таймлайн сессии (R8) — этап 4

- Над временной линией переключатели: «Пропущенные и отменённые», «Не-события» (герои, НПС, заметки, материалы), «Журнал», «Автозаписи». По умолчанию выключены все, кроме журнала без автозаписей.
- По умолчанию на линии только пункты видов «сцена», «событие», «цель», «последствие».

## 9. Сущности (R9) — этап 2 и 3

- Клик по имени сущности / часов / секрета / арки / игрока в любом разделе открывает боковую панель; «Открыть полностью» — страница `/local/campaign/:id/entity/:entityId`.
- Новые типы: `event` (событие: дата в мире, место, участники, последствия), `lore` (лор/статья: раздел, текст). Импорт событий и лора из Лорбука — в эти типы.

## 10. Интеграции (R10) — этап 1

- Раздел «Интеграции» (группа «Обмен»). Карточки ролей: мир, стол, система. Состояние: «Не подключено → Подключить» или «Подключено: <имя> ✓ · Сменить · Отвязать». Выпадающих списков в покое нет.
- Мастер подключения: 1) роль и система (для стола — ЛавГеймс или КК9), 2) мир/кампания/система, 3) проверка связи (паспорт возможностей), 4) правила отправки по типам.
- «Публикация» больше не содержит выбора связей; в ней очередь и выбор назначения для пачки.

## 11. Игроки (R11) — этап 5

- Серверная коллекция `players`: профиль (имя, контакты, предпочтения, табу и границы, доступность по дням), общие заметки, личные заметки мастера (видны только автору).
- Страница «Игроки» на главной. В кампании игрок выбирается из справочника; персонажи по кампаниям видны в профиле.
